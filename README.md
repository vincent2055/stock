# A股复盘看盘工作台（stock）

A 股收盘后全维度复盘看盘工作台，产出自包含单文件 HTML 报告（`trade-review.html`），覆盖指数、涨跌家数、涨停/跌停/炸板、国际指数、板块多周期龙头、龙头股/领跌股、自选股五维评分与持仓分级。

## 数据源

- 东方财富（国际指数、涨跌停/炸板、自选股行情）
- 东方财富妙想选股器（板块排名、周期龙头股、领跌股）
- 新浪财经（指数、北证50）
- 腾讯自选股 westock-mcp（可选，连接失效时自动降级到上述源）

## 目录结构

- `trade-review.html` —— 交付物（自包含，浏览器直接打开）
- `*.py` —— 数据采集与计算脚本（collect / compute / assemble / generate_html 等）
- `sector_data.json` —— 124 个申万二级板块基准名单（脚本依赖）
- `*.json` / `*.txt` —— 采集与计算的中间数据快照

## 说明

- 脚本内含本机绝对路径，换机运行前需按需调整。
- 涨红跌绿（A股惯例）；行情为收盘一次性快照，复盘导向，页面不实时刷新。
- ⚠️ 本内容由 AI 基于公开数据整理生成，仅供参考，不构成任何投资建议。投资有风险，决策需谨慎。
